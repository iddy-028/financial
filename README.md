---

## 📌 Overview

**Spend Wise** is a lightweight and intuitive expense tracking application built to improve financial awareness and control.

Many people struggle to understand where their money goes. This system solves that problem by providing a **clear, structured, and easy-to-use platform** for tracking and analyzing daily expenses.

---

## 🎯 Objectives

- Provide a simple and efficient expense tracking solution  
- Improve financial awareness and discipline  
- Offer clear insights into spending behavior  
- Support better financial decision-making  

---

## ✨ Core Features

- 📊 Expense tracking system  
- 📁 Smart categorization of expenses  
- 📈 Financial summaries and insights  
- 🔍 Transparent money management  
- ⚡ Fast and lightweight performance  

---

## 🧠 How It Works

1. Users enter their daily expenses  
2. The system stores and organizes the data  
3. Expenses are categorized  
4. Users view summaries and insights  
5. Better financial decisions are made

## ⚙️ Installation & Setup

### 1. Clone Repository
git clone https://github.com/nmcosta5/GROUP3.git  

### 2. Navigate to Folder
cd GROUP3  

### 3. Setup Environment
- Install XAMPP / WAMP / LAMP  
- Move project into `htdocs`  

### 4. Setup Database
- Create a MySQL database  
- Import `.sql` file from `/database`  

### 5. Run the Project
Open browser and go to:  
http://localhost/GROUP3
